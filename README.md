# 📊 Stock Market Data Pipeline & Dashboard

## 🚀 Project Overview

This project is a simple data pipeline that:
- Gets stock data from an API
- Processes it using Python
- Stores it in PostgreSQL
- Visualizes it in Power BI

---

## 🏗️ Flow

API → Python → PostgreSQL → Power BI

---

## ⚙️ Tools Used

- Python
- PostgreSQL
- Power BI

---

## 📊 What the Dashboard Shows

- Stock prices over time
- Average return
- Volatility (risk)
- Moving averages
- Filters by stock and date
